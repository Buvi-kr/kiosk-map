# 🌌 포천아트밸리 스마트 키오스크 & 모바일 경로안내 시스템 (v1.1.0)

포천아트밸리 현장 방문객을 위한 **대형 키오스크 경로 안내 시스템(`index.html`)** 및 **QR 스마트폰 모바일 가이드(`qr.html`)** 통합 웹 애플리케이션입니다.

---

## 🏛️ 시스템 구조 및 연동 흐름

```
+-------------------------------------------------------------------------+
|                  [1] 현장 대형 키오스크 (index.html)                    |

|  - 우측 정량 줌 컨트롤러 (+ / - / ⟲) & 원터치 목적지 안내              |

+-------------------------------------------------------------------------+
                                    │
                       📱 방문객 스마트폰으로 QR 스캔
                                    ▼
+-------------------------------------------------------------------------+
|                   [2] 모바일 스마트 가이드 (qr.html)                    |
|  - 18개 실측 앵커 기반 들로네 삼각분할(Delaunay) + 바리센트릭 국소 아핀 변환 |
|  - GPS 지수이동평균(EMA) 필터링 & 실시간 정확도 반경 원(Accuracy Circle)    |

```

## 🚀 주요 기능 및 조작 방식

### 1. 🖥️ 대형 키오스크 시스템 (`index.html`)
* **3337x2101 초고해상도 벡터 조감도**: WebP 고화질 지도 위 실시간 경로 흐름 및 화살표 애니메이션
* **키오스크 맞춤형 줌 컨트롤**:
  * 터치스크린 및 마우스 조작 환경에 최적화된 **우측 플로팅 정량 줌 버튼(`➕`, `➖`, `⟲`)**
  * 1손가락/마우스 드래그 패닝 및 휠 줌 지원
* **하단 대형 모바일 가이드 QR 배너**:
  * 조명 빛반사를 유발하던 상단 초소형 네온 QR을 제거하고, **하단에 100px급 대형 화이트 QR 배너** 배치
  * 방문객이 멀리서도 스마트폰 카메라로 즉시 스캔 가능
  * 접속 도메인(`window.location.origin + .../qr.html`) 자동 감지 동적 QR 생성
* **무인 스마트 자동 순환 & 유휴 복귀**:
  * 방문객 조작 후 20초간 입력이 없으면 전체 지도로 자동 복귀
  * 무조작 1분 주기마다 주요 목적지 경로를 자동으로 순환 시연
* **관리자 모드 (히든 기능)**:
  * 화면 우측 하단 영역을 **5회 연속 탭**하면 관리자 바 오픈
  * 출발지 프리셋 원터치 전환 (매표소 ↔ 천문과학관 ↔ 관광정보센터)
  * 경로 제작 모드(노드 추가/삭제/숲길 분기 지정) 및 JSON 내보내기/복사

### 2. 📱 스마트 모바일 가이드 (`qr.html`)
* **들로네 삼각분할(Delaunay) & 바리센트릭(Barycentric) 국소 아핀 변환**:
  * 기존 전역 IDW의 먼 앵커 끌림 왜곡을 완전히 제거하고, 18개 실측 앵커 삼각망 내부에서 1:1 선형 아핀 보간
  * 앵커 지점 오차 0px 일치 및 구간별 선형 이동 보장
* **GPS 지수이동평균(EMA) 필터링 & 정확도 반경 원(Accuracy Circle)**:
  * 절벽/계곡 다중경로 반사파로 인한 순간 튐 노이즈를 EMA($\alpha=0.4$)로 매끄럽게 완충
  * GPS 수신 오차($\pm X\text{m}$)에 비례한 반투명 파란색 정확도 반경 원을 실시간 렌더링
* **모바일 네이티브 제스처**:
  * **2손가락 핀치 줌 & 1손가락 패닝**: 자유로운 지도 확대/축소 및 이동
  * **더블 탭 줌 토글**: 지도를 톡톡 2번 터치하면 전체보기 ↔ 내 위치 줌인 전환
  * 사용자가 수동 줌 조작 시 GPS 갱신으로 화면이 튀지 않는 스마트 뷰포트 고정
* **마스터 도로망 자석 스냅 & 다익스트라 최단 경로 안내**:
  * 🏞️ **천주호 전망대**: 산마루 계단 능선을 타고 전망대로 이어지는 파란 윗길 단일 코스
  * 🌲 **힐링숲 산책로**: 진입로(빨강) ➔ 분기점 `🌲 숲길 입구` ➔ 능선 숲길(초록) 2색 분할
* **현장 실사 GPS 인스펙터 (관리자/개발자 시크릿 모드)**:
  * 상단 **로고/타이틀 영역을 5회 연속 연타** 시 실시간 GPS 좌표 인스펙터 오픈 (일반 방문객 오터치 방지)
  * 현재 위치의 **위경도(WGS84)**, **지도 SVG 변환 좌표 [X, Y]**, **가장 가까운 거점**, **수신 오차(m)** 즉시 확인
  * 📋 **`JSON 데이터 복사`** / 📍 **`위경도 좌표 복사`** 버튼으로 현장 실측 좌표를 원클릭으로 클립보드에 복사 가능
* **화면 꺼짐 방지 (Wake Lock API)**: 이동 중 스마트폰 화면 꺼짐 자동 방지

### 3. 📐 마스터 도로망 스튜디오 (`editor.html`)
* 29개 통합 도로망 구간 및 170개 교차점 노드 시각화
* **실시간 길찾기 테스트 (`🧪`)**: 지도 위 2점을 찍어 다익스트라 최단 경로 알고리즘 검증
* 노드 드래그 앤 드롭 편집 및 JSON 원클릭 내보내기

## 🎯 정밀도 향상을 위한 데이터 수집 가이드 (방법 A & B)

실측 수동 측량의 번거로움을 없애고 전경도의 원근 왜곡을 극복하기 위한 2가지 표준 전략입니다:

### 🖥️ 방법 A: 위성사진 대조 매칭 (데스크 작업, 발품 0%)
구글 어스(Google Earth) 또는 카카오/네이버 위성 지도(Top-Down 정사영상)와 조감도 양쪽에서 뚜렷하게 식별 가능한 랜드마크를 짝지어 앵커를 50~100개로 확장합니다:
* **대상 랜드마크**:
  * 건물 지붕 꼭짓점/모서리 (천문과학관, 김광우미술관, 관리사무소, 화장실 등)
  * 천주호 저수지 절벽 외곽선 및 댐/자갈 사면 경계
  * 모노레일 상·하부 승강장 및 지주 기둥 위치
  * 주차장 구획선 모서리 및 도로 급커브 꺾임점
* **작업 방식**:
  1. 위성 지도에서 해당 지점의 위경도(`lat, lng`) 복사
  2. 조감도(`index.html` 또는 `editor.html`)에서 동일 지점의 SVG `[X, Y]` 픽셀 좌표 확인
  3. `qr.html`의 `ALL_GPS_ANCHORS`에 `{ name, svg: [X, Y], lat, lng }` 형태로 추가

---

### 🚶 방법 B: 1회 걷기 트랙 로깅 & 곡선 정합 (현장 QA 산책 1회)
하나하나 점을 찍지 않고, 산책로를 한 바퀴 걸으며 연속 GPS 트랙을 수집하여 도로망(`MASTER_ROAD_DATA`)과 호 길이(Arc-length) 기준으로 자동 매칭합니다:
1. 스마트폰으로 `qr.html` 접속 후 **상단 타이틀 5회 연속 탭**하여 인스펙터 오픈
2. **`▶️ 걷기 트랙 기록 시작`** 버튼 터치 후 폰을 들고 산책로 코스를 평소처럼 보행
3. 산책 완료 후 **`⏹️ 걷기 기록 종료 & JSON 다운로드`** 터치
   * 수백 개의 실시간 GPS 트랙(`[{lat, lng, acc, t}, ...]`)이 JSON 파일로 다운로드 및 클립보드 복사됨
4. 저장된 트랙 JSON 데이터를 조감도 도로망에 자동 곡선 정합(Curve Fitting)하여 촘촘한 앵커 데이터셋으로 변환

## ☁️ Cloudflare 호스팅 및 배포 가이드

본 프로젝트는 외부 백엔드 API나 빌드 도구 없이 브라우저 자체적으로 구동되는 **100% 순수 클라이언트 정적 웹 애플리케이션**입니다. Cloudflare Pages 또는 Cloudflare Workers 정적 호스팅에 완벽하게 호환됩니다.

### 1. Cloudflare Pages 배포 방법
1. Cloudflare Dashboard ➔ **Workers & Pages** ➔ **Create application** ➔ **Pages** 선택
2. GitHub 리포지토리 연동 또는 Direct Upload(파일 업로드)
3. 빌드 설정:
   * **Framework preset**: `None`
   * **Build command**: (비워둠)
   * **Build output directory**: `/` (루트 디렉터리)
4. 배포 완료 후 제공되는 `https://<project-name>.pages.dev` 주소로 즉시 운영 가능

### 2. 운영 시 필수 점검 사항 (중요)
> [!IMPORTANT]
> **1. HTTPS 보안 프로토콜 필수 (SSL)**
> 모바일 스마트폰의 GPS 위치 권한(`navigator.geolocation`)과 화면 켜짐 유지(`Wake Lock`)는 브라우저 보안 정책상 **HTTPS 연결에서만 동작**합니다. Cloudflare는 기본적으로 자동 SSL 인증서를 제공하므로 안전하게 동작합니다.

> [!TIP]
> **2. QR 코드 자동 연동**
> `index.html`은 접속된 Cloudflare 도메인을 자동 인식하여 `qr.html` 주소로 QR 코드를 생성합니다. 별도의 도메인 하드코딩 수정 없이 커스텀 도메인을 연결해도 자동으로 동작합니다.
