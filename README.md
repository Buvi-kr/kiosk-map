# 🌌 포천아트밸리 스마트 키오스크 & 모바일 경로안내 시스템 (v1.0.0)

포천아트밸리 현장 방문객을 위한 **대형 키오스크 경로 안내 시스템(`index.html`)** 및 **QR 스마트폰 모바일 가이드(`qr.html`)** 통합 웹 애플리케이션입니다.

---

## 🚀 주요 기능 및 시스템 구조

### 1. 📱 스마트 모바일 가이드 (`qr.html`)
* **실시간 GPS 연동**: 방문객의 현재 위치를 지도 위에 파란색 펄스 핀(`📍`)으로 실시간 표시
* **2D 정사영 아핀 변환 (`gpsToSvg`)**: 실측 GPS 2개 기준점(천문과학관, 매표소)을 기반으로 중심 끌림 오차 없는 1:1 완벽 지도 투영
* **통합 도로망 다익스트라 최단 경로 안내**: 사용자가 직접 색칠하고 RDP로 압축한 170개 노드 마스터 도로망 기반 실시간 최단 경로 연결
* **특화 산책로 코스 지원**:
  * 🏞️ **천주호 전망대**: 산마루 계단 능선을 타고 전망대로 이어지는 파란 윗길 단일 코스
  * 🌲 **힐링숲 산책로**: 진입로(빨강) ➔ 분기점 `🌲 숲길 입구` ➔ 능선 숲길(초록) 완벽 분할
  * ☕ **전망카페**: 메인 산책로를 통한 직행 코스
  * 🚻/🥤 **편의시설**: 지도 속 실제 인쇄된 남녀 휠체어 화장실 및 파란색 음료수 컵 매점 아이콘과 100% 일치
* **2열 터치 최적화 UI & 즉시 안내 배너**: 모바일 한 손 조작에 최적화된 하단 탭 및 즉시 경로 노출

### 2. 🖥️ 대형 키오스크 시스템 (`index.html`)
* **3337x2101 초고해상도 조감도 벡터 렌더링**: WebP/JPG 자동 Fallback 지원
* **출발지 선택 기능**: 천문과학관 ↔ 매표소 양방향 원터치 전환
* **실시간 경로 그리기 애니메이션**: 경로 흐름 오버레이 및 이동 화살표 애니메이션
* **관리자 편집 모드**: 도로 노드 미세 조정 및 커스텀 경로 관리

### 3. 📐 마스터 도로망 스튜디오 (`editor.html`)
* 29개 통합 도로망 구간 및 170개 교차점 노드 시각화
* **실시간 길찾기 테스트 (`🧪`)**: 지도 위 2점을 찍어 최단 경로 다익스트라 알고리즘 검증 가능
* 노드 드래그 앤 드롭 및 JSON 원클릭 내보내기

## 📂 파일 구성
```text
├── index.html                   # 포천아트밸리 대형 키오스크 경로안내 메인
├── qr.html                      # 모바일 QR 스캔 실시간 GPS 가이드
├── editor.html                  # 마스터 도로망 스튜디오 & 경로 테스터
├── master_roads_unified.json    # 84% 압축 최적화된 통합 도로망 그래프 데이터
├── qrcode.min.js                # 오프라인 단독 구동 QR 코드 생성 엔진
├── 아트밸리_전경도_안내_v2.webp    # 키오스크용 고화질 조감도 원본 (1.3MB)
├── 아트밸리_전경도_안내_v2_mobile.webp # 모바일 전용 초경량 조감도 (640KB)
├── 천문과학관_로고.png            # 로고 이미지
├── 안내프로그램.bat              # 키오스크 로컬 서버 원클릭 실행기
└── 이전버전/                     # 구버전 원본 JPG(4.5MB), 이전 빌드본 아카이브
```

## 💻 실행 방법

### 로컬 웹 서버 실행
```bash
python -m http.server 8080
```

* **키오스크 화면**: `http://localhost:8080/index.html`
* **모바일 가이드**: `http://localhost:8080/qr.html`
* **도로망 스튜디오**: `http://localhost:8080/editor.html`
