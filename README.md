# 포천아트밸리 키오스크 경로안내 시스템 (운영 가이드)

## 📌 개요
포천아트밸리를 방문하는 관람객을 위한 무인 키오스크(1080×1920 세로형 터치 디스플레이) 경로 안내 웹 애플리케이션입니다.
인터넷 연결 없이 **단일 HTML 파일과 배경 이미지 파일**만으로 구동되며, 직관적인 길찾기 인터랙션 및 고화질 애니메이션을 제공합니다.

---

## 📁 필수 구성 파일

키오스크 구동을 위해 아래 2개 파일이 **반드시 같은 폴더(디렉토리)** 안에 위치해야 합니다:
- `아트밸리_경로안내.html` (메인 키오스크 구동 파일)
- `아트밸리_전경도_안내_v2.jpg` (3337 × 2101 초고화질 안내도 배경 이미지)

---

## 🚀 실행 방법

1. 키오스크 PC 바탕화면 폴더에 위 두 파일을 복사합니다.
2. 웹 브라우저(Chrome, Edge 등)로 `아트밸리_경로안내.html`을 실행합니다.
3. 브라우저에서 **전체화면(F11)** 모드로 전환하여 운영합니다. (완전 오프라인 구동)

---

## ⚙️ 설치 장소(단말기)별 시작 위치 설정

키오스크가 설치된 위치에 따라 현위치를 자동 설정할 수 있습니다.

### 방법 A: 파일 이름 변경 (추천)
- **천문과학관 기기:** `아트밸리_경로안내_천문과학관.html`
- **매표소 기기:** `아트밸리_경로안내_매표소.html`
- **관광정보센터 기기:** `아트밸리_경로안내_관광정보센터.html`

### 방법 B: 브라우저 URL 파라미터 사용
- 천문과학관: `.../아트밸리_경로안내.html?start=astro`
- 매표소: `.../아트밸리_경로안내.html?start=ticket`
- 관광정보센터: `.../아트밸리_경로안내.html?start=info`

## ✨ 주요 기능 및 핵심 구현 사항

1. **인쇄본 노란 점(Vector Dot) 100% 실측 앵커 동기화**
   * 안내도 이미지에 인쇄된 각 시설물의 노란 원형 앵커 점(`천문과학관`, `천주호`, `전망카페`, `산마루공연장`, `모노레일 승·하차장`, `조각공원`, `힐링숲`, `검표소` 등)의 실제 픽셀 좌표를 정밀 매핑하여 경로 선이 시설물 앵커로 정확히 이어집니다.

2. **PDF 300 DPI 초고화질 헤더 제거 배경 (3337 × 2101)**
   * PDF 벡터 원본에서 상단 종이용 인쇄 띠를 제거하고 300 DPI로 무손실 추출하여, 2~3배 줌인 시에도 글자와 아이콘이 칼같이 선명합니다.

3. **텍스트 중복 없는 네온 펄스 마커 링 UI**
   * 배경 이미지에 이미 박스 라벨이 있으므로 글자 겹침을 방지하고, 목적지에는 시선이 집중되는 **네온 펄스 마커 링(`Pulse Marker Ring`)**을 띄웁니다.

4. **복수 경로 (기본 빨강 🔴 / 대안 파랑 🔵) 지원**
   * 보행로(평지길)와 호수 직통 계단길 등 복수 경로가 있는 목적지는 선택 UI를 통해 분기 안내합니다.

## 🔐 관리자 모드 및 경로 수정 (제작 모드)

1. **진입 방법:** 화면 **[우측 하단 모서리]**를 **2초 안에 빠르게 5번 연속 터치/클릭**합니다.
2. **경로 수정:**
   * **`[🖊 경로 제작 모드]`** 클릭
   * 시작 위치(`매표소`, `천문과학관`, `관광정보센터`) 및 목적지 버튼 선택
   * 지도 위를 클릭하여 새로운 경로 점(Point)들을 순서대로 연결
   * `[+ 경로 추가]`: 파란색 대안 경로 추가
   * `[↩ 취소]`: 마지막 점 취소 / `[🗑 초기화]`: 전체 초기화
3. **내보내기 & 영구 저장:**
   * `[⇩ 내보내기]` 클릭 후 생성된 JSON 코드를 복사하여 `아트밸리_경로안내.html` 내 `ALL_ROUTES`에 붙여넣고 저장합니다.

## 🛡️ 무인 키오스크 안정성 기능 (하드닝)

- **터치 줌/더블탭 줌 차단:** 관람객의 임의 확대 조작 차단
- **롱프레스(우클릭) 차단:** 컨텍스트 메뉴 및 텍스트 선택 방지
- **20초 유휴 자동 초기화:** 20초간 조작이 없을 시 안내를 멈추고 전체 화면으로 자동 복귀
