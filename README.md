## 🌟 핵심 기능 하이라이트 (Key Features)

```mermaid
graph LR
    A[📍 현장 방문객] -->|QR 스캔| B(📱 qr.html 모바일 가이드)
    C[🖥️ 대형 키오스크] -->|QR 생성 및 길안내| A
    D[🛠️ 관리자] -->|1:1 도로망 편집| E(🗺️ editor.html GIS 에디터)
    E -->|마스터 도로망 SSOT| F[(data/master_artvalley_roads.json)]
    F --> B
    F --> C
```

* 🚀 **100% 단일 방사형 그래프 (Single Unified Road Network)**
  * 47개 거점 노드 및 28개 보행로 링크를 완벽히 융합하여 **도달 불가 구간 0건**, 절벽 관통 오류를 원천 차단했습니다.
* 🌿 **범용 2대 코스 스마트 선택 엔진 (카카오맵 / 네이버지도 스타일)**
  * 천문대/산마루 ↔ 천주호/조각공원/호수공연장 등 상하행 양방향 전 구간에서 **`[♿ 완만(평지)]`** vs **`[🪜 윗길(계단)]`** 코스를 실시간으로 동시 제공합니다.
  * 지도 위 메인 실선과 대안 점선이 원터치로 매끄럽게 스왑(Swap)됩니다.
* 🚻 **편의시설 좌·우 2열 직관적 그리드 배치**
  * 모바일 화면에서 [좌측열: 화장실 5종] / [우측열: 스낵·카페 5종]으로 시원하게 분할 배치.
  * 실시간 GPS 기반으로 "⚡가장 가까운 화장실/매점"을 0.1초 만에 자동 계산하여 추천합니다.
* 🛰️ **2초 주기 실시간 GPS 오차 보정 & 부드러운 카메라 무빙**
  * 모바일 GPS 좌표(WGS84)를 실측 앵커 변환 알고리즘으로 SVG 픽셀에 1:1 초정밀 매핑.
  * 깜빡임 없는 경로 갱신과 핀치 줌 / 더블 탭 확대 / 터치 패닝 제스처 완벽 지원.

## 📱 핵심 웹 애플리케이션 구성 (HTML 상세 소개)

포천아트밸리 프로젝트는 목적과 사용자 디바이스에 따라 특화된 3가지 메인 웹 애플리케이션으로 구성되어 있습니다:

### 1. 📲 `qr.html` — 모바일 방문객 전용 스마트 QR 내비게이션 (Main App)
> **"현장 방문객의 손 안에서 펼쳐지는 초정밀 스마트 길안내 서비스"**

* **주요 대상**: 스마트폰으로 QR 코드를 스캔한 실제 현장 도보 관광객
* **핵심 기능**:
  * 📍 **실시간 내 위치 트래킹 (GPS Blip)**: 파란색 펄스 애니메이션으로 현재 서 있는 위치를 실시간 표시.
  * 🧭 **실시간 다익스트라 최단 보행로 계산**: 목적지 터치 시 실제 산책로만을 따라 굽이굽이 흐르는 최적 경로 렌더링.
  * 🔄 **양방향 2대 코스 스마트 토글**: 상단 배너에서 `[♿ 완만(평지)]`과 `[🪜 윗길(계단)]`을 터치 한 번으로 자유롭게 전환.
  * 🌲 **힐링숲 산책로 2색 분할 안내**: 전망카페까지 진입로(빨강) + 능선 숲길 구간(초록) 완벽 시각화.
  * ⚡ **초소형 플로팅 안내 캡슐**: 지도 화면을 가리지 않는 컴팩트 배너 (목적지, 거리, 도보 소요시간).
  * 🛰️ **현장 실측 GPS 인스펙터**: GPS 수신 정확도, 실시간 위경도, 걷기 트랙 로거 탑재.

<br>

### 2. 🖥️ `index.html` — 대형 터치 키오스크 종합 안내 시스템
> **"포천아트밸리 입구 및 주요 거점에 설치되는 대화면 터치 스크린 솔루션"**

* **주요 대상**: 매표소, 관광정보센터, 휴게 광장의 대형 4K / FHD 터치 키오스크
* **핵심 기능**:
  * 🗺️ **대화면 고해상도 전체 전경도 렌더링**: 포천아트밸리 전역을 시원한 대화면으로 탐색.
  * 📲 **개인 모바일 연동 QR 코드 즉시 생성**: 키오스크에서 확인한 경로를 자신의 스마트폰으로 그대로 담아갈 수 있는 다이내믹 QR 생성 엔진.
  * 🎯 **원터치 거점 탐색**: 주요 명소(천주호, 천문과학관 등) 및 편의시설 원터치 길안내.
  * 🛡️ **키오스크 전용 자동 리셋 타이머**: 사용자 조작이 없을 시 메인 대기 화면으로 자동 복귀.

<br>

### 3. 🛠️ `editor.html` — 1:1 도로망 그래프 GIS 시각 에디터
> **"개발자 없이도 도로망을 마우스로 직접 긋고 보정하는 관리자용 비주얼 툴"**

* **주요 대상**: 현장 관리자 및 도로망 유지보수 운영자
* **핵심 기능**:
  * ✏️ **비주얼 인터랙티브 도로망 편집**: 47개 노드 드래그 이동, 노드 간 연결선(Polyline) 생성/삭제.
  * 📐 **24대 핵심 GPS 앵커 1:1 좌표 보정**: 실측 위경도와 지도 픽셀의 오차를 시각적으로 실시간 미세 조정.
  * 💾 **단일 표준 JSON 원클릭 Import / Export**: 작업한 도로망 데이터를 `master_artvalley_roads.json` 형식으로 즉시 추출 및 백업.
  * 🔍 **실시간 다익스트라 경로 시뮬레이터**: 에디터 내에서 출발지와 도착지를 클릭하여 경로가 정상 작동하는지 즉시 검증.

### 1. 도로망 그래프 토폴로지 (Graph Topology)

### 2. Cubic Bezier 곡선 경로 스무딩 알고리즘
```javascript
// 꺾인 직선 경로를 유기적인 자연 산책로 곡선으로 렌더링하는 스무딩 엔진
function smoothPath(pts) {
  if (pts.length < 2) return '';
  if (pts.length === 2) return `M ${pts[0][0]},${pts[0][1]} L ${pts[1][0]},${pts[1][1]}`;
  let d = `M ${pts[0][0]},${pts[0][1]} `;
  for (let i = 0; i < pts.length - 1; i++) {
    const p0 = pts[i - 1] || pts[i], p1 = pts[i], p2 = pts[i + 1], p3 = pts[i + 2] || p2;
    d += `C ${p1[0] + (p2[0] - p0[0]) / 6},${p1[1] + (p2[1] - p0[1]) / 6} ${p2[0] - (p3[0] - p1[0]) / 6},${p2[1] - (p3[1] - p1[1]) / 6} ${p2[0]},${p2[1]} `;
  }
  return d.trim();
}
```

## 📜 2026-08-19 종합 개발 & 트러블슈팅 패치노트

### 🛠️ [Bug 1] 6개 고립 서브그래프(Island) 분리 버그 규명 및 단일망 통합
* **현상**: 매표소, 정보센터, 주차장 등 입구 쪽에서 출발 시 다익스트라가 실패하여 **절벽과 산을 뚫고 지나가는 직선 Fallback** 발생.
* **원인**: 그래프 파싱 결과, 도로망 47개 노드가 6개의 서로 다른 컴포넌트로 끊겨 있었음.
* **해결**: 5개 고립 섬을 실제 보행로에 맞게 브릿징하여 **도달 불가 0건의 단일 컴포넌트(1 Single Component)**로 융합 완료.

### 🛠️ [Bug 2] 모노레일 하차장(30번) 23번 우회 루프 버그 척결
* **현상**: 천문대에서 30번 하차장으로 갈 때 바로 앞 80px 거리에 있는 매점(28번)을 지나치면서도 23번 삼거리까지 내려갔다 유턴함.
* **원인**: 30번 노드가 오직 23번에만 외길(`[30, 31, 23]`)로 연결되어 있었음.
* **해결**: `28 ↔ 30` 직통 도로를 개통하여 23번 경유 없는 **초직통 최단거리 코스** 완성.

### 🛠️ [Bug 3] 39번-36번 겹침 노드 정리
* **해결**: 6px 거리에 위치한 중복 노드 39번을 36번에 완전 흡수 통합하고 `[36, 38]` 직통 링크로 도로망 경량화.

### 🚀 [Feature 1] 상하행 범용 2대 코스 스마트 선택 엔진 (`♿ 완만(평지)` vs `🪜 윗길(계단)`)
* **해결**: 천문대/산마루 ↔ 천주호/조각공원/호수공연장 전 구간 상하행 양방향에서 평지길과 계단길을 선택할 수 있는 스마트 토글 배너 및 대안 점선 렌더링 시스템 구축.

### 🎨 [Feature 2] 편의시설 2열 분할 레이아웃 & 아이콘 정밀화
* **해결**: 좌측(화장실 5종) / 우측(스낵·카페 5종) 2열 분할 정렬, 모노레일 하부탑승장(13번), 매표소(6번), 입구(4번 `🚪`), 공연장(`🎈`) 매핑 완료.

## 🛠️ 기술 스택 (Tech Stack)

| 구분 | 사용 기술 | 설명 |
| :--- | :--- | :--- |
| **Core** | `HTML5`, `CSS3 (Vanilla)`, `Modern JavaScript (ES6+)` | 프레임워크 없는 초경량 제로 디펜던시 |

| **Data Format** | `GeoJSON Compatible Structured JSON (SSOT)` | 단일 표준 마스터 데이터셋 관리 |
